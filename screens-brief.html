ARTI STATUS

Tiap status nandain tahap brief & script lo. Klik status pill di brief card buat liat di tahap mana lo sekarang.

Draft

Draft — Brief baru, belum ditulis script-nya. Mulai nulis sekarang.

Sedang ditulis

Sedang ditulis — Lagi nulis script. Belum disubmit ke admin.

Siap review

Siap review — Script udah lo submit. Admin lagi review / voting.

Perlu revisi

Perlu revisi — Admin minta revisi. Edit script sesuai feedback, submit ulang.

Disetujui

Disetujui — Script di-acc admin. Lanjut upload video.

Ditolak

Ditolak — Script ditolak admin. Hubungi admin kalo mau diskusi.

Selesai

Selesai — Video published / final. Brief closed.
